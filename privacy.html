隐私说明

本说明区分静态官网、本地推理、第三方 API 和离线授权。更新日期：2026年11月27日。

官网访问与下载

本网站不设账号、支付或音频上传接口，不使用第三方统计脚本，也不设置营销 Cookie。你点击下载后，浏览器会向网站服务器请求安装包。

网站服务器和其运营者配置的网络服务可能保留常规访问日志，例如 IP、访问时间、浏览器信息和请求路径。具体日志保存与使用方式由实际网站运营者负责；这不等同于桌面应用上传音频。

本地推理

选择本地引擎时，参考录音与语音生成在你的电脑上处理。模型文件、生成音频、音色库和历史记录保存在本机。首次准备依赖、下载模型时会访问相应的软件或模型服务。

第三方 API

如果你主动配置并使用云端 API，请求会发送给你选择的服务商。请自行了解该服务的数据处理和隐私条款。官网对本地模式的描述不适用于第三方服务。

离线激活

应用使用有效的设备硬件标识生成机器码，用于单机授权。机器码是经过处理的摘要，界面不直接显示硬件序列号。设备识别和激活码验证均在本地执行，不连接授权服务器。

你向发行者提供机器码以获取激活码。发行者可能在签发台账中保存机器码、激活码、签发时间和必要的客户备注，用于人工签发与售后。不要向任何人提供发行者私钥或其保护密码。

你可以采取的措施

选择本地模式以在本机处理声音；妥善保管自己的录音和激活码；删除数据前先备份。关于购买、授权补发或具体运营主体的信息，请联系发行者：fangazio@hotmail.com。
