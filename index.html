DUAL ENGINE ARCHITECTURE

本地与云端

在「设置 → AI Provider」自由切换。追求完全离线与声音克隆选本地引擎；无独立显卡或轻量合成可选云端 API。

本地模型

离线全功能

基于 VoxCPM2 / 1.5 / 0.5B，支持声音设计、可控克隆与极致克隆。
模型准备完成后，可完全离线生成，音频与素材全部留在本地。

  • 支持声音设计、参考音频克隆及 SenseVoice 辅助转写
  • 分阶段资源调度与按需加载，任务队列清空自动释放显存
  • 音色库、批量长文本队列与历史记录本地持久化管理

需安装本地推理环境与模型，运行速度与可用功能取决于本机硬件及所选模型。

云端 API

轻量零权重

接入 OpenAI 兼容的语音合成服务（如硅基流动等）。
无需下载本地语音模型或依赖本机 GPU 推理。

  • 填写 API 地址、Key、模型与音色即可直接合成语音
  • 无需安装数 GB 模型权重，低配办公本亦可流畅使用
  • 与本地模式共用同一套创作工作台、历史记录与导出流程

需基础运行环境、网络连接和服务账号，费用由服务商另计；当前应用 API 模式不支持克隆或自动转写。

BUILT FOR PRODUCTION · V1.0.3

面向真实创作的桌面工程细节

不只封装推理，更聚焦加载耗时、显存礼让、素材管理与本机数据安全。

01 · V1.0.3 加速

冷加载与连续合成大幅提速

采用元骨架加载跳过冗余参数初始化，融合底层归一化算子并优化自回归推理循环；相同参考音频在连续与批量克隆中自动复用 CPU 特征缓存，降低峰值显存且不牺牲音质。

02 · 显存礼让

分阶段资源调度与自动释放

下载和选择模型绝不预占显存。支持「桌面流畅优先」与「生成速度优先」两种策略，默认在队列完成后立即卸载模型，有任务执行时安全锁定防误释。

03 · 资产工作流

音色库、批量队列与原生导出

音色库保留完整参考音频并自动生成最长 5 秒独立试听；批量任务支持按空行/行/句切分长文、失败重试与 ZIP 打包；历史记录支持多选删除与系统弹窗另存。

04 · 本地边界

本机回环通信与离线永久授权

后端仅监听 127.0.0.1 随机端口并校验每次启动生成的会话令牌。V1.x 离线激活与日常验签均不联网，无需注册账号，所有录音与生成结果完全保存在本地目录。

GETTING STARTED

四步开始使用

应用本体、推理运行时与模型权重分层交付，升级应用无需重复下载模型。

STEP 01

安装桌面应用

下载并运行 Windows 安装包，数秒内完成桌面端与本地服务部署。

STEP 02

本机离线激活

复制首次启动显示的机器码联系发行者，粘贴 V1.x 永久激活码解锁。

STEP 03

配置引擎环境

按引导检测/安装本地推理运行时，或在设置中直接填写云端 API 配置。

STEP 04

选择模型创作

在模型管理下载或导入本地模型，即可进行设计、克隆与批量导出。
